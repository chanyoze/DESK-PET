# DeskPet

바탕화면을 돌아다니는 데스크톱 마스코트 + 개인 작업 도우미. **Windows 10/11 · macOS**.

작업 표시줄을 걸어다니고, 앉고, 자고, 가끔 말을 건다. 드래그해서 던질 수도 있다.
여기에 **할 일(정각 recap · 반복) · 스티커 메모 · 빠른 메모 · 클립보드 기록 · 바로가기 · Claude Code 알림 · 빌드/서버 알림 · 자동 업데이트**를 붙였다.

> 이 문서는 **쓰는 법**이다. 만들고 고치고 빌드하는 쪽은 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## 설정 창

메뉴 · 트레이의 **설정…**. 바꾸면 바로 저장되고 바로 적용된다 (Esc 로 닫기).

| 묶음 | 항목 |
|---|---|
| 캐릭터 | 크기(작게 · 보통 · 크게 — 바꾸면 캐릭터가 다시 뜬다) · 모니터(여럿일 때) · 분위기 · 혼잣말 · 커서 |
| 할 일 · 정각 알림 | 정각마다 짚기(끄기 · 30분 · 1시간 · 2시간) · 시간(기본 9~18시) · 평일만 · todo.md 열기 |
| 알림 | 윈도우 알림(급한 것만) · Claude Code 연결 / 끊기 · Claude 소식 말하기 |
| 도구 | 단축키 셋 — 칸을 누르고 새 조합을 누르면 바뀐다 (Esc 취소 · Del 끄기 · 기본값). 다른 프로그램이 쓰는 중이면 표시된다 · 클립보드 기록 켜고 끄기 |
| 성능 | **움직임** 가볍게 · 보통 · 부드럽게 (CPU ↔ 매끄러움) · 그래픽 가속 자동 · 켜기 · 끄기 (다음에 켤 때 적용) |
| 일반 | 윈도우 시작할 때 실행 (exe 일 때) · 업데이트 자동 확인 · 지금 확인 · 새로 바뀐 것 · 로그 · 설정 폴더 · 버전 |

- 메뉴가 길어져서 한 번 정하면 그만인 설정은 여기로 옮겼다. 메뉴엔 자주 누르는 것만 남았다
- 커서 **도망가기** 중엔 캐릭터를 잡기 어려우니 트레이 → **커서** 에도 남겨 뒀다
- 값은 `%APPDATA%\deskpet\settings.json` (맥 `~/Library/Application Support/deskpet`) 에 저장된다

## 할 일

### `%APPDATA%\deskpet\todo.md`

평범한 마크다운 체크리스트다. **어디서 고쳐도 된다** — 할 일 카드, 메뉴의 "할 일 추가…", 빠른 메모, 메모장 · VS Code,
그리고 **Claude Code 세션에서 "todo 에 ○○ 추가해줘" / "○○ 끝났다고 체크해줘"**. 앱은 파일이 바뀌면 바로 다시 읽는다.

```markdown
# 할 일

## 2026-09-30              ← 날짜 (일자별)
- [ ] 분류 없는 일
### 오전                    ← 분류 (이름 자유 — 오전 · 오후 · 3시 전까지 · 회의 …)
- [ ] 승인모듈 검토 (~11:00)  ← 기한: (~시각) · (~10-01) · (~10-01 15:00)
  설명 한 줄                ← 두 칸 들여쓴 줄은 설명
### 3시 전까지
- [ ] 톰캣 로그 확인
- [x] 문서 정리

## 반복                     ← 반복 할 일의 틀 — 그날이 되면 그날 목록에 들어간다
- [ ] 퇴근 전 커밋 (평일 17:30)
### 보고
- [ ] 주간보고 (매주 월)
- [x] 운동 (매일)            ← 체크해 두면 쉬기

## 언젠가                   ← 기약 없는 백로그 ("백로그" 라고 써도 된다)
- [ ] 개발표준 다시 읽기
```

- **설명** — 항목 바로 아래 **두 칸 들여쓴 줄**은 그 항목의 설명이다. 입력 창에선 첫 줄이 할 일, 다음 줄부터 설명
  (여러 개를 한꺼번에 넣을 땐 "줄마다 따로" 체크). 카드엔 제목 아래 작은 글씨로
- **카드에서 바로 수정 · 삭제** — 줄에 마우스를 올리면 `✎` 수정 · `×` 지우기(두 번 눌러야), 글 더블클릭도 수정.
  체크는 체크박스로만 (글을 눌러 실수로 체크되지 않게)
- **분류는 직접 등록한다** — 입력 창의 분류 칸에 이름을 쓰고 `+ 등록` 하면 버튼으로 남는다 (마우스를 올려 `×` 로 빼기,
  이미 적힌 할 일은 그대로). 처음엔 예시로 오전 · 오후 · 3시 전까지 · 퇴근 전. 버튼에 없는 이름도 칸에 그냥 쓰면 된다
- **분류 이름에 시각이 있으면 그게 기한**이 된다 (항목에 따로 안 적었을 때): 오전 → 12:00, 오후 → 18:00, "3시 전까지" · "15시 전" → 15:00
- **기한 알림** — 시각이 있는 기한은 10분 전과 그 시각에 한 번씩 알려 준다 (근무 시간과 상관없이)
- 날짜 제목 없이 맨 위에 적힌 항목은 언젠가(백로그)로 본다 — 예전 평평한 목록도 그대로 읽힌다
- 앱이 고치는 건 항목 줄과, 넣을 때 필요한 날짜 · 분류 제목뿐이다. 다른 줄은 그대로 둔다
- PC 마다 따로다 (동기화하지 않는다) — 회사 할 일이 공개 저장소에 올라가지 않게 일부러 userData 에 뒀다

### 반복 할 일

- 규칙: `(매일)` · `(평일)` · `(주말)` · `(매주 월,수)` · `(매월 1일)`, 뒤에 시각을 붙이면 그날의 기한 — `(평일 17:30)`
  - `매월 31일` 은 짧은 달엔 말일에
- **그날 처음 켤 때 · 자정이 지날 때 · 파일이 바뀔 때** 그날에 해당하는 틀을 오늘 목록(같은 분류 · 설명)에 넣는다
- 오늘 넣은 걸 지우거나 다른 날로 옮겨도 **그날은 다시 만들지 않는다** (설정 `repeatMade` 에 그날 만든 제목을 적어 둔다)
- 틀을 **체크해 두면 쉬기** — 휴가 때 등. 틀의 체크는 "오늘 끝낸 수" 에 들어가지 않는다
- 카드 `언젠가` → `반복` 보기에서 틀 목록 (규칙 칩), `+` 로 추가. 입력 창의 **반복** 칸에서 매일 · 평일 · 주말 · 매주(요일 버튼) · 매월(날짜) + 시각

### 할 일 카드

- 오른쪽 위. 기본은 **오늘**. `◀ ▶` 로 날짜를 넘기고, 오른쪽 버튼으로 **날짜 → 언젠가 → 반복** 보기, 제목을 누르면 오늘로
- 오늘 보기 맨 위엔 지난 날짜에서 **밀린 것** — 두 개 이상이면 **오늘로 · 언젠가로 · 끝냄** 으로 한꺼번에 정리한다
  (분류 · 설명은 그대로, 그날 시각 기한은 오늘 같은 시각으로. 비게 된 지난 날짜 제목은 지운다)
- 분류별로 묶고, 기한 칩은 지나면 빨강 · 1시간 안이면 주황
- 체크박스로 바로 체크, `+` 로 추가 (입력 창에 날짜 · 언젠가 · 반복 · 분류 · 기한 칸), `‒` 접기, `×` 닫기 (메뉴 "할 일 카드 보이기" 로 다시)
- 오른쪽 아래 모서리를 끌어 크기 조절 (저장된다), 머리줄을 끌어 옮긴다 (위치 저장)
- 글자는 투명 창이 못 받아서 작은 **입력 창**(Ctrl+Enter 저장, Esc 취소)을 캐릭터가 있는 모니터에 띄운다

### 정각 recap

- 평일 9~18시, 정각마다 주인공이 남은 할 일을 말해 준다 (5개까지, 나머지는 "+N개 더"). 간격 · 시간 · 평일만은 설정 창에서.
  메뉴 "지금 정리해줘" 로 바로 부를 수도 있다
- 대상 — 오늘 안 끝낸 일 + 밀린 일. 기한 지난 것 · 가까운 것부터 (`~15:00 (2시간 반 남음)` · `(지남)`). 언젠가는 "지금 정리해줘" 때 개수만
- **재촉 한마디** — 목록 끝에 가장 급한 일 하나를 캐릭터 말투로: 4시간 안이면
  "톰캣 로그 확인은 2시간 반 안에 끝내야 해. 부지런히 해!", 지났으면 "…벌써 기한 지났어"
- 할 일이 하나도 없으면 정각엔 조용히 넘긴다. 다 끝냈으면 오늘 끝낸 개수를 말한다. Claude 알림이 오면 떠 있던 recap 말풍선은 양보한다

## 스티커 메모

- 메뉴 "메모 붙이기…" (또는 빠른 메모의 "스티커 메모") → 입력 창에서 쓰고 색(노랑 · 분홍 · 초록 · 파랑 · 회색) 고르기
- 더블클릭 · `✎` 편집, `×` 두 번 눌러 지우기, `‒` 접기, 모서리로 크기 조절. `%APPDATA%\deskpet\notes.json`
- 캐릭터가 카드 위에 있으면 캐릭터가 먼저 잡힌다
- **메모 · 카드 숨기기** — 메뉴와 트레이 둘 다 있다 (화면 공유 · 회의 때)

## 도구 — 빠른 메모 · 클립보드 기록 · 바로가기

어느 창에서든 단축키로 작은 창(팔레트)을 띄운다. 탭 셋은 `Ctrl+1 · 2 · 3`, 닫기는 `Esc` 나 다른 곳 클릭.
캐릭터 메뉴 "도구" · 트레이에서도 연다. 필요할 때만 만들고 닫으면 없앤다 (늘 떠 있는 창을 늘리지 않으려고).

| 단축키 (기본) | 탭 | 하는 일 |
|---|---|---|
| `Ctrl+Alt+Space` | **빠른 메모** | 적고 Enter → **오늘 할 일 · 언젠가 · 스티커 메모** 중 고른 곳에. 첫 줄이 할 일, 다음 줄부터 설명. 📋 로 클립보드 글 붙이기 |
| `Ctrl+Alt+V` | **클립보드 기록** | 앱을 켠 뒤 복사한 글 최근 25개 — 찾기, ↑↓ · Enter 로 다시 복사(그다음 `Ctrl+V`). 📌 고정 · ✕ 빼기 · 잠깐 멈춤 · 비우기 |
| `Ctrl+Alt+O` | **바로가기** | 자주 여는 **폴더 · 파일 · 주소 · 명령**을 등록해 두고 찾기 · Enter 로 열기. 순서 바꾸기 · 고치기 · 지우기(두 번) |

- **클립보드 기록은 앱을 끄면 지워진다** — 비밀번호 · 사내 데이터가 복사돼 있을 수 있어서 디스크에 남기지 않는다.
  📌 고정한 것만 `%APPDATA%\deskpet\clipboard-pins.json` 에 남는다. 내용은 로그에도 안 찍는다. 아주 긴 글(2만 자 넘음)은 건너뛴다
- 바로가기는 `%APPDATA%\deskpet\shortcuts.json`. 종류는 자동으로 정한다 — `https://…` 는 브라우저, 있는 경로는 기본 프로그램
  (폴더는 탐색기), 그 밖은 명령으로 실행 (예: `code "C:\work\DESK-PET"`, 배치 파일)
- **단축키는 설정 창 → 도구** 에서 바꾼다. 다른 프로그램이 먼저 잡고 있으면 등록이 실패하고 알려 준다 (그래도 메뉴에서는 열린다)
  - IntelliJ 등은 `Ctrl+Alt+V` 를 쓰기도 한다 — 겹치면 이쪽 단축키가 이긴다. 불편하면 바꿀 것

## Claude Code 연동

설정 창 → 알림 → **Claude Code 연결하기** 한 번이면 끝이다 (윈도우).
`~/.claude/settings.json` 에 훅이 들어가고, 실행 중인 Claude Code 세션에도 바로 적용된다.

| Claude Code 에서 | 캐릭터 |
|---|---|
| 작업이 끝남 (20초 넘게 걸린 턴) | `[프로젝트] 끝났어` — 5분 넘으면 걸린 시간도 말한다 |
| 짧은 대답 (20초 미만) | 조용히 넘긴다 — 터미널을 보고 있을 테니까 |
| 허락이 필요함 (`permission_prompt`) | 커서 쪽으로 달려와서 알려 준다 |
| 입력을 기다림 (`idle_prompt` 등) | `네 대답 기다리고 있어` |
| 오류로 끊김 (`StopFailure`) | 쓰러졌다 일어난다 (쓰러지는 동작이 있는 캐릭터) |
| 일하는 중 | 주인공이 멀리 안 가고 앉아서 기다린다. 3분 넘으면 꾸벅꾸벅 졸다가, 끝나면 깨서 알려 준다 |

- **세션 현황** — 메뉴의 "Claude 세션" 에 떠 있는 세션이 최근 소식 순으로 나온다 (`DESK-PET · 작업 중 3분째`, `허락 기다림 30초 전` …)
- **그 창으로 가기** — Claude 말풍선(점선 밑줄)이나 세션 항목을 누르면 그 세션의 터미널 창이 앞으로 온다 (↗ 표시가 창을 찾아 둔 세션)
  - Windows Terminal 은 창 단위라 탭이 여러 개면 창만 앞으로 온다
- 설정 창의 **Claude 소식 말하기** 로 연결은 둔 채 말만 끌 수 있고, **연결 끊기** 는 우리 훅만 뺀다. 다른 훅은 건드리지 않는다
- 앱이 꺼져 있으면 훅은 1초 안에 조용히 끝난다 — Claude Code 를 막지 않는다. 동작 방식은 [개발 문서](docs/DEVELOPMENT.md#claude-code-훅-동작-방식)

## 빌드 · 서버 알림 (`deskpet.ps1`)

앱이 켜질 때 `%APPDATA%\deskpet\deskpet.ps1` 을 만들어 둔다. Node 없이 PowerShell 만으로 캐릭터에게 말을 시킨다.

```powershell
$pet = "$env:APPDATA\deskpet\deskpet.ps1"
& $pet say "점심 먹자" -Mood happy                      # 그냥 말 시키기 (normal | happy | alert | fail)
& $pet run "mvn -q package" -Name 빌드                  # 끝나면 성공/실패 + 걸린 시간. 종료 코드는 그대로 돌려준다
& $pet watch C:\tomcat\logs\catalina.out -Name 톰캣    # 기동 완료/실패 줄이 나오면 알려 주고 끝난다
```

- `watch` 기본값은 톰캣 · 스프링 부트 기동 메시지다. 다른 로그는 `-Ok 정규식` `-Fail 정규식` 으로 바꾼다
- 실패(`fail`)면 알림 카드가 빨갛고 캐릭터가 쓰러진다 (쓰러지는 동작이 있는 캐릭터)
- `run` 의 명령은 따옴표로 한 덩어리로 넘긴다 (`-q` 같은 옵션을 PowerShell 이 가로채지 않게)
- HTTP 로 직접 보내려면 [개발 문서 — 외부에서 말 시키기](docs/DEVELOPMENT.md#외부에서-말-시키기)

## 알림 — 대화와 구분

| | 대화 (혼잣말 · 반응 · recap) | 알림 카드 (Claude · 기한 · 빌드 · 업데이트) |
|---|---|---|
| 모양 | 흰 둥근 말풍선 | 어두운 카드 + 왼쪽 색 띠, 윗줄 `Claude · 프로젝트 · 15:42`, 아래 작은 글씨로 캐릭터 한마디 |
| 색 띠 | — | 끝남 초록 · 허락 주황 · 입력 대기 노랑 · 오류 빨강 · 기한 파랑 · 업데이트 청록 |
| 누르면 | 넘기기 | 그 세션의 터미널로 (↗ 표시) · 업데이트 창 |

- **놓친 알림** — 카드가 사라져도 남는다. 주인공 머리 위 빨간 배지 `🔔 N` + **트레이 아이콘 빨간 점**.
  배지를 누르면 최근 알림 목록 (누르면 그 터미널로), 열면 모두 읽음. 메뉴 · 트레이 "최근 알림 보기"
- **윈도우 알림 (토스트)** — 메인 모니터 오른쪽 아래, 알림 센터에 남는다. **급한 것만**: Claude 허락 요청 · 오류,
  할 일 기한, 빌드 실패, 새 버전. 작업 끝남은 말풍선만 (잦아서). 설정 창 → 알림 에서 끄고 켠다
- 작업 표시줄 깜빡임은 안 된다 — 작업 표시줄 버튼이 없는 창이라서. 트레이 빨간 점이 그 역할

## 캐릭터 추가하기

기본으로 자체 제작 캐릭터 하나가 들어 있다. **에셋은 각자 준비한다** — 이 저장소에도, 배포 파일에도 남의 캐릭터 그림은 들어 있지 않다.

### 내 그림으로 만들기 (가장 쉬움)

설정 창 → 캐릭터 → **+ 내 그림으로 만들기** (또는 메뉴 캐릭터 → "+ 내 그림으로 만들기…").

1. 이름을 적고, 동작 칸에 **PNG · GIF · WEBP 를 끌어다 놓는다** — 대기(필수) · 걷기 · 잠 · 들렸을 때 · 쓰다듬을 때
   - GIF 는 움직이는 그대로(원래 속도), PNG 여러 장은 이름 순서대로 한 동작
   - 대기만 있어도 된다 — 걷기 · 쓰다듬기는 대기 그림으로 **통통 튀며**, 나머지는 대기 그림으로 대신한다
2. **배경 지우기** — 흰 배경처럼 테두리가 꽉 찬 그림이면 저절로 켜진다 (테두리와 같은 색을 투명하게, 오차 조절)
3. **바라보는 쪽** — 그림 속 캐릭터가 보는 방향. 반대로 걸을 땐 좌우를 뒤집어 그린다 (정면이면 그대로)
4. 키 · 걷는 속도 · 도트 그림(픽셀 그대로) · 혼잣말(한 줄에 하나)을 정하고, 오른쪽 미리보기로 동작마다 확인 → **저장**
   ("저장하고 바로 주인공으로" 를 켜 두면 바로 바뀐다)

- 만든 캐릭터는 설정 창 캐릭터 목록에서 **고치기 · 숨기기 · 지우기**. 받아 온 캐릭터는 숨기기만 (지우면 다음에 켤 때 다시 받는다)
- 지금 나와 있는 캐릭터는 숨기거나 지울 수 없다 — 먼저 다른 캐릭터를 주인공으로
- 파일은 `%APPDATA%\deskpet\characters\my-…` (시트 png + `character.json`). 업데이트해도 그대로다

### 주고받기 (`.deskpet` 파일)

만든 캐릭터를 파일 하나로 건네고 받는다 — 지인마다 원하는 캐릭터를 만들어 주기 좋다.

- **보내기** — 설정 창 캐릭터 목록에서 **내보내기** → `이름.deskpet` 저장 (기본 바탕화면). 메신저 · 메일로 건네면 된다.
  "보내는 사람" 칸에 이름을 적어 두면 받은 쪽 목록에 "○○ 님" 으로 나온다
- **받기** — 받은 `.deskpet` 파일을 **설정 창에 끌어다 놓거나** [가져오기]. 같은 캐릭터가 있으면 덮어쓰기 · 따로 추가 · 취소를 묻는다
- 받은 캐릭터는 내가 만든 것처럼 고치기 · 숨기기 · 지우기 · 다시 내보내기가 된다
- 파일 안엔 그림과 설정만 있다 — 받는 앱이 그림 · 설정 파일이 아닌 것, 폴더 밖을 가리키는 경로가 든 파일은 거절한다
- 게임에서 뽑은 그림처럼 남의 저작물이 든 캐릭터는 개인끼리만 — 공개된 곳에 올리지 말 것

### 직접 넣기 (Spine · 게임 시트)

캐릭터 폴더를 `%APPDATA%\deskpet\characters\<이름>\` 에 넣으면 메뉴 **캐릭터** 에 나타난다.

| 종류 | 넣을 것 |
|---|---|
| Spine 2D (3.8) | `character.json` + `.skel` + `.atlas` + `.png`, 그리고 Spine 런타임 한 번 — `%APPDATA%\deskpet\vendor\spine\spine-webgl.js` ([3.8 브랜치](https://raw.githubusercontent.com/EsotericSoftware/spine-runtimes/3.8/spine-ts/build/spine-webgl.js), 라이선스 때문에 동봉하지 않는다) |
| 스프라이트 시트 | `character.json` + 시트 `.png` (RPG Maker · 불가사의 던전 스타일) |

- `character.json` 쓰는 법 · 게임에서 뽑는 레시피 · 포켓몬 스프라이트는 [개발 문서 — 캐릭터](docs/DEVELOPMENT.md#캐릭터--코드는-공개-에셋은-각자-byoa)
- 앱 업데이트와 상관없이 이 폴더에서 계속 읽는다. 지우지 않고 목록에서만 빼려면 `character.json` 에 `"hidden": true`

## 업데이트

앱이 켤 때 1분 뒤 · 그 뒤 3시간마다 릴리스를 본다 (설정 창에서 자동 확인을 끌 수 있다). 새 버전이 있으면

1. 알림 카드(청록 띠) + 윈도우 알림 — "새 버전 v0.16.0 — 눌러서 업데이트". 메뉴 맨 위 · 트레이에도 `⬆ 업데이트`
2. 누르면 확인 창 — **지금 업데이트 / 나중에 / 이 버전 건너뛰기** (바뀐 것 요약이 같이 보인다)
3. 지금 업데이트 → 받기 (카드에 % 표시) → **sha256 확인** (깨진 파일이면 설치 안 함) → 바꿔 끼우고 다시 켜진다
   - 윈도우 포터블: 새 exe 를 옛 exe 옆에 받고, 옛 앱이 꺼진 뒤 새 exe 가 뜨고, 옛 exe 는 지워진다.
     자동 시작이 켜져 있었으면 새 경로로 옮겨 건다
   - 맥: zip 을 풀어 지금 `.app` 자리에 바꿔 넣고 다시 연다 (못 바꾸는 자리면 Finder 로 새 앱을 보여 준다)
4. 새 앱이 "v0.15.0 → v0.16.0 업데이트했어" 라고 알려 주고, **"새로 바뀐 것" 창**에 그 사이 버전들의 요약을 보여 준다
   - 손으로 exe 를 바꿔 끼워도 같다 — 지난번 실행 버전보다 올라갔으면 처음 켤 때 한 번. 처음 설치하면 띄우지 않는다.
     설정 창 "새로 바뀐 것" 으로 다시 볼 수 있다

- **캐릭터 · 설정 · 할 일은 그대로다** — 전부 `%APPDATA%\deskpet` (맥 `~/Library/Application Support/deskpet`) 에 있고 앱만 바뀐다
- 트레이 · 설정 창 "업데이트 확인 / 지금 확인" 으로 바로 볼 수 있다

## 맥 (macOS)

- 맥에서는 Dock 아이콘 없이 메뉴바에만 뜨고, 모든 데스크톱(Spaces)에 보인다
- 코드 서명 인증서가 없어서 처음 한 번 터미널에서 `xattr -cr /Applications/DeskPet.app`
- Claude Code 알림 연결 · 그 터미널로 · `deskpet.ps1` 은 PowerShell 이라 아직 윈도우 전용
- 맥 공개판은 처음 켤 때 포켓몬 하데리어 · 늪짱이 · 갈모매를 받아 온다 (인터넷 한 번). 메뉴 캐릭터에서 바꿔 쓴다
- 맥 빌드 · 통파일은 [개발 문서 — 맥](docs/DEVELOPMENT.md#맥-macos)

## 문제가 생기면

- **로그** — `%APPDATA%\deskpet\deskpet.log` (설정 창 → 일반 → 로그). 클릭 · 창 찾기 · 업데이트 · 오류가 남는다 (클립보드 내용은 안 남긴다)
- 알림 · 카드가 안 눌리면 한 번 껐다 켜 볼 것 — 그래도 그러면 로그를 같이 남겨 주면 된다
- 캐릭터가 화면 밖에 있으면 메뉴 · 트레이 "가운데로 불러오기"

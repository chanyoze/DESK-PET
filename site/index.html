캐릭터 추가하기

기본 캐릭터가 하나 들어 있습니다. Spine 2D 스켈레톤이 있으면 원하는 캐릭터를 넣을 수 있습니다. 

%APPDATA%\deskpet\characters\내캐릭터\
    character.json
    foo.skel
    foo.atlas
    foo.png

character.json 은 이렇게 씁니다.

{
  "name": "표시할 이름",
  "renderer": "spine",
  "skeleton": "foo.skel",
  "atlas": "foo.atlas",
  "height": 250,
  "animations": {
    "idle": "Relax", "walk": "Move", "sit": "Sit",
    "sleep": "Sleep", "pet": "Interact"
  }
}

Spine 런타임도 한 번 받아서 아래 경로에 두면 됩니다. 3.8 브랜치여야 합니다. 

%APPDATA%\deskpet\vendor\spine\spine-webgl.js

https://raw.githubusercontent.com/EsotericSoftware/spine-runtimes/3.8/spine-ts/build/spine-webgl.js
캐릭터 에셋은 각자 준비합니다. 이 앱에는 자체 제작 캐릭터만 들어 있습니다. 게임이나 다른 작품의 에셋은 포함되어 있지 않고, 앞으로도 포함하지 않습니다. 개인적으로 사용하는 것과 배포하는 것은 다른 문제입니다.

알림 보내기

앱은 127.0.0.1:45678 에만 열리는 작은 서버를 띄웁니다. 빌드 스크립트든 뭐든 캐릭터에게 말을 시킬 수 있습니다. 

curl -X POST http://127.0.0.1:45678/say ^
  -H "Content-Type: application/json; charset=utf-8" ^
  -d "{\"text\":\"빌드 끝났어\",\"mood\":\"happy\"}"

mood 는 normal / happy / alert 이고, 말풍선 색과 캐릭터 반응이 달라집니다.

# 마리나 · 사마리 — 대사 쓰기용 캐릭터 노트

**2026-09-25 조사.** 게임 데이터(`www/data/*.json` 의 대사)와 Playable Non-Playables 모드 데이터,
[Fear & Hunger Wiki](https://fearandhunger.wiki.gg/)를 교차 확인해서 정리했다.
DeskPet의 혼잣말·반응·대화 대사는 전부 이 노트를 바탕으로 **새로 쓴 것**이고 원작 문장을 옮기지 않았다.

> 스포일러 주의: 두 캐릭터의 배경이 조금 나온다. 대사에는 어두운 부분을 쓰지 않는다 (아래 "쓰지 않는 것").

---

## 마리나 (오컬티스트)

| | |
|---|---|
| 나이 · 출신 | 18세, 프레헤빌 출신. 바티칸에서 오컬트를 공부하다 고향에 돌아왔다 |
| 말투 | **반말, 수다스럽다.** 비꼬는 농담을 하고 "방금 거 비꼰 거야" 하고 스스로 짚는다 |
| 속마음 | 쿨한 척하지만 겁이 많다. 무서운 티를 안 내려고 애쓴다 |
| 좋아하는 것 | 책·서점, 딸기 소다·사이다, 오컬트 도구(분필, 의식의 원), 조용히 혼자 있을 곳 |
| 싫은 것 | 야영, 하수도, 촌구석 같은 고향 |
| 꿈 | **론돈에 작은 오컬트 가게**를 차리는 것 |
| 호칭 | 주인공을 "잠꾸러기"라고 부른다 → 데스크톱에서는 사용자에게 쓴다 |

대사 방향: 가볍고 비꼬는 수다. 부드러운 츤데레가 아니라 **말 많은 오컬트 덕후**.
무기(칼·산탄총·권총)는 그녀의 원래 설정이 아니므로 "익숙하지 않은 물건" 톤으로 쓴다.

## 사마리 (견습생)

| | |
|---|---|
| 정체 | 원작에서는 NPC. 바티칸 쪽 의식과 얽힌 아이로, 마음 읽기와 피 마법을 쓴다 |
| 말투 | **반말, 짧고 건조하다.** 평소엔 말이 적고 체념적이다 |
| 마리나 앞 | 말을 더듬고("M, 마리나…") 놀라면 **"캬악!"** 한다 |
| 마리나와의 관계 | 원작: 사마리만 마리나를 오래 알고 지켜봐 온 일방적인 관계 (마리나는 사마리를 모른다) |
| | 모드: 코미디풍 짝사랑. 마리나는 "키 큰 애"라고 부르며 귀찮아하면서도 받아 준다 |
| 모드에서 더해진 면 | 호수 같은 처음 보는 것에 신기해한다, 무도회에 같이 가자고 한다 |

대사 방향: 말수 적고 건조한데 마리나 얘기만 나오면 무너진다. 원작의 집착은 **수줍은 호감**
정도로 낮춘다.

## 둘의 대화

사마리가 먼저 말을 걸고 마리나가 받아치는 구도가 기본. 마리나는 귀찮아하면서도 결국 받아 주고,
사마리는 짧게 대답하다 가끔 속마음이 새어 나온다. (모드의 "키 큰 애", 무도회, 호수 소재를 쓴다)

## 분위기 두 가지

메뉴의 **분위기**로 고른다 (설정 `tone`).

| | 가볍게 (기본) | 원작처럼 |
|---|---|---|
| 대사 | 위의 성격 그대로, 어두운 소재 없음 | 어두운 대사(`linesDark`)가 절반쯤 섞인다 |
| 사마리의 시선 | 수줍은 호감 | 섬뜩한 톤 — 마음 읽기, "어제 몇 시에 잤는지 알아" |
| 서사 소재 | — | 사마리의 짧은 수명 · 죽음관, 마리나 아버지(암시만), 달과 사흘의 축제, 신들 이름, 교회 · 먹을거리(간접 언급만) |
| 대화 | 기본 8개 | + 어두운 대화 5개 (`dialoguesDark`) |
| 변신 | 그림만 | 변신할 때 대사 |
| 붉은 호 | — | 사마리가 평균 10분에 한 번 손을 베고 붉은 빛과 함께 다른 자리로 순간이동. 세게 던져도 35% 확률로 공중에서 빠져나간다 |
| 악몽 | — | **새벽 2~5시에만**, 평균 30분에 한 번(같은 캐릭터는 40분 안에 다시 안 나옴) 피 흘리며 기어가다 일어난다 |
| 쓰러짐 | — | 아주 세게 던지면 30% 확률로 쓰러졌다가 일어난다 |

## 쓰지 않는 것

원작처럼 분위기에서도 다음은 쓰지 않는다.

- **기생체(crab) 변형 · 주사** — 요청으로 뺐다
- 손 베기는 사마리 순간이동 **연출 그림으로만**. 대사나 농담으로는 다루지 않는다
- 성적인 내용 전부 (특히 미성년과 얽힌 원작 소재), 미성년 음주
- 캐릭터의 개인 정체성을 농담이나 반전 소재로 쓰기

아래는 **가볍게** 분위기의 기준이다.

- 살해 · 유해 · 참수 · 십자가형 · 식인 등 고어 소재
- 자해, 피 칠하기 (사마리의 "내 피로—" 는 마리나가 바로 끊는 개그로만)
- 사마리의 몸 · 수명 문제
- 스토킹 · 몰래 본 사생활 · 성적인 내용 · 미성년 음주
- 달그을림(변신) 설정 설명 — 변신 연출은 그림으로만 보여 준다
- 캐릭터의 개인 정체성을 농담이나 반전 소재로 쓰기

## 대사 구조 (DeskPet)

레시피의 `manifest.lines` 와 `dialogues` 에 들어 있다.

| 키 | 언제 |
|---|---|
| `idle` `walk` `run` `sit` `sleep` | 그 상태에서 가끔 (20~60초마다 판단, 최소 90초 간격) |
| `morning` `afternoon` `evening` `night` | 시간대가 바뀌면 하루 한 번 인사 |
| `together` | 둘이 같이 있을 때 30% 확률로 상대 얘기 |
| `armed:knife` `armed:shotgun` `armed:pistol` | 무기를 들고 있으면 절반은 무기 얘기 |
| `picked` `thrown` `landed` | 집어 들 때 · 세게 던질 때 · 던져진 뒤 착지할 때 |
| `petted` `woken` | 쓰다듬기 · 자는 중에 눌렀을 때 |
| `longRun` | 3시간 넘게 켜 두면 가끔 |
| `dialogues` | 둘이 한가하면 2.5~5분에 한 번 주고받는다 (`me` / `you`) |

같은 묶음 안에서는 섞은 순서대로 한 바퀴 다 돌기 전까지 같은 말을 반복하지 않는다.

# 로드맵

목표는 "상용 제품 복제"가 아니라 **내 캐릭터를 내 바탕화면에 살게 하는 것**.
단계마다 눈에 보이는 결과가 나오도록 쪼갰다.

- [x] 개발 옵션: `--trace`, `--start=`, 렌더러 콘솔 포워딩

### 여기서 배운 것

벽 타기를 붙여보고 알게 된 것: **아트가 좋아도 동작이 안 따라온다.**

- 정면을 보는 캐릭터는 "기어오르는" 것처럼 보이지 않는다. 지금 자세는
  "모서리에 매달려 있다"까지가 한계다. 진짜 등반처럼 보이려면
  **측면/후면 전용 아트**가 따로 있어야 한다.
- 이건 어떤 기성 에셋을 가져와도 똑같다. 게임 SD 캐릭터는 정해진 카메라
  각도용으로 만들어져서 등반 포즈도, 측면 뷰도 없다.
- 즉 아트를 구하는 것으로는 이 문제가 안 풀리고, **동작 설계 + 그에 맞는
  아트**를 같이 만들어야 한다. Step 4에서 파츠를 그릴 때 정면뿐 아니라
  측면 세트를 함께 계획할 것.

## ✅ Step 1.7 — Spine 렌더러 + 캐릭터 시스템 (v0.3, 완료)

- [x] 캐릭터 시스템 — `characters/<이름>/character.json`, 트레이에서 전환
- [x] 렌더러 추상화 — `PartsView`(Canvas 2D) / `SpineView`(WebGL) 동일 인터페이스
- [x] Spine 3.8 WebGL 렌더러 (메시 지원을 위해 Canvas 백엔드 대신 WebGL)
- [x] 에셋을 IPC로 실어 보내기 — `file://` XHR이 막혀 spine AssetManager를 못 쓴다
- [x] 셋업 포즈 바운즈로 캔버스 원점 계산 (원점이 바운즈 중앙이 아니다)
- [x] `npm run fetch-spine` — 런타임은 재배포하지 않고 각자 받는다
- [x] `--shot` 개발 옵션 — 창 내용만 캡처 (전체화면 앱에 가려져도 검증 가능)
- [x] 명일방주 켈시 기지 SD로 동작 확인 (걷기·앉기·벽 타기·낙하)

### 여기서 배운 것

**Step 1.5의 예측이 그대로 맞았다.** 게임 에셋은 `Default / Interact / Move /
Relax / Sit / Sleep` 여섯 개뿐이라, 벽 타기는 `Move`를 재생할 수밖에 없다.
올라가는 위치와 물리는 우리 코드가 만들지만 **자세는 걷는 모습 그대로**다.

즉 두 방식의 성격이 명확해졌다:

| | 게임 에셋(Spine) | 자체 파츠 리그 |
|---|---|---|
| 그림 품질 | 프로급 | 그림 실력만큼 |
| 있는 동작 | 6개 고정 | 원하는 만큼 |
| 새 동작 추가 | 불가능 | 함수 하나 |
| 벽 타기 자세 | 걷기로 대체 | IK로 실제로 잡음 |
| 배포 | 불가 | 자유 |

**둘 다 유지할 가치가 있다.** 그래서 렌더러를 갈아끼우는 구조로 만들었다.

- [x] **로컬 알림 서버** (127.0.0.1 전용) — 외부 도구가 캐릭터에게 말을 시킨다
- [x] **Claude Code 완료 알림** — Stop / Notification 훅
- [x] **리마인더** — 5 / 25(포모도로) / 60분, 메뉴에서 취소
- [x] **설정 저장** — 캐릭터 · 크기 · 리마인더가 재시작 후에도 유지

### 여기서 배운 것

- 투명 창은 `focusable: false` 라서 **텍스트 입력을 받을 수 없다.** 리마인더를
  프리셋(5/25/60분)으로 만든 이유다. 자유 입력을 넣으려면 창을 잠깐
  focusable 로 바꾸거나 별도 입력 창이 필요하다.
- 떠 있는 UI(말풍선·메뉴)도 히트 테스트에 포함해야 한다. 안 그러면 클릭이
  그대로 아래 창으로 통과해 메뉴를 누를 수 없다.
- HTTP 본문을 문자열로 이어붙이면 청크 경계에서 한글이 깨진다.
  Buffer를 모아 한 번에 UTF-8로 디코드해야 한다.

## ✅ Step 2.5 — 혼잣말 + 배포 (v0.5, 완료)

- [x] **혼잣말** — 상태(대기/걷기/앉기/잠)와 시간대(아침·점심·저녁·밤)에 맞춘 대사
  - 20~60초마다 판단, 최소 90초 간격, 시간대 인사는 하루 한 번
  - 캐릭터별 대사는 매니페스트의 `lines` 로 덮어쓸 수 있다
  - 메뉴에서 끄고 켤 수 있고 설정에 저장된다
- [x] **electron-builder 포터블 exe** (96MB, 설치 불필요)
- [x] 캐릭터·Spine 런타임을 `%APPDATA%/deskpet` 에서도 읽는다
      (패키징하면 앱 내부는 asar 라 손댈 수 없어 사용자 폴더가 필요하다)
- [x] 배포물에서 게임 에셋·Spine 런타임 제외 검증 (asar 목록으로 확인)

### 배포에서 지킨 선

- 빌드에 들어가는 캐릭터는 **자체 제작 파츠 리그 하나뿐**이다
- Spine 런타임은 재배포에 라이선스가 필요해 동봉하지 않고 사용자가 받는다
- 게임에서 뽑은 에셋은 `%APPDATA%` 에만 있고, 배포 파일에는 없다
